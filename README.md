# 柴犬丟平底鍋 🐕🍳

像素風柴犬在菜市場互丟平底鍋的小遊戲。

## 玩法
- 按住 **空白鍵** 或 **滑鼠左鍵** 蓄力，下方指針會左右來回跑
- 放開時指針停在 **綠色完美區** → 完美命中，扣 20 血
- 停在 **黃色邊緣區** → 擦邊命中，扣 7 血
- 其他位置 → MISS
- 和電腦輪流投擲，先打光對方 100 血的人獲勝

## 專案結構
```
index.html          遊戲主頁
css/style.css       版面樣式（畫面自動縮放）
js/game.js          遊戲程式（蓄力判定、動畫、AI）
assets/             像素角色與背景素材
說明.txt            離線版說明
開始遊戲.bat        本機雙擊啟動（Windows）
```

## 素材
以「像素風格柴犬在菜市場買菜」原圖延伸製作，包含
待機 / 走路 / 跑步 / 投擲 / 受擊 五組動作精靈圖。
