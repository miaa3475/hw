柴犬丟平底鍋 🐕🍳
==================

【怎麼玩】
1. 雙擊「開始遊戲.bat」（或直接打開 index.html）就會用瀏覽器開啟遊戲。
2. 按住 空白鍵 或 滑鼠左鍵 → 開始蓄力，下方指針會左右來回跑。
3. 放開時，指針如果停在綠色「完美區」＝ 完美命中，扣對手 20 血。
4. 停在黃色邊緣 ＝ 擦邊命中，扣 7 血。
5. 其他位置 ＝ MISS，對手毫髮無傷。
6. 你和電腦輪流丟平底鍋，先把對方血量打到 0 的人獲勝。

【檔案結構】
柴犬丟平底鍋/
├─ index.html          遊戲主頁
├─ 開始遊戲.bat        雙擊即可開啟遊戲
├─ css/style.css       版面樣式（畫面自動縮放）
├─ js/game.js          遊戲程式（蓄力判定、動畫、AI）
└─ assets/
   ├─ bg-market.png        菜市場背景
   ├─ dog-sprite-idle.png  待機
   ├─ dog-sprite-walk.png  走路
   ├─ dog-sprite-run.png   跑步
   ├─ dog-sprite-cast.png  投擲
   └─ dog-sprite-hit.png   受擊

【備註】
- 圖片素材由「像素風格柴犬在菜市場買菜」的原圖延伸製作。

- 建議用 Chrome / Edge 開啟，並可開到全螢幕觀看。
